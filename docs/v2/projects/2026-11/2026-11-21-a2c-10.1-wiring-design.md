# A-2c §10.1 wiring design (detached-response receipts through transport completion)

Status: design note; implementation starts after A-3 acceptance (it is the executor that publishes
the typed PublicationLease and must be the base).

## Contract (design §4 / §10.1 / adopted §9.4)

A request's response must be retired at exactly one edge: the SERVER-side closure of the transport
completion (SSE/HTTP response fully delivered) — never at the queue/executor completion, never by
caller-side destruction alone. The executor already publishes:
- `ResponseLease` terminal transitions (worker-owned completion hook: Queued -> Attached ->
  Delivering),
- `PublicationLease` (retained delivery state),
- `Snapshot.delivering` (post-production, pre-transport-completion count).

The missing edges (A-2c wiring):
1. **Transport-completion receipt**: when the server finishes writing the response, it must resolve
   the request's `PublicationLease` state with an exactly-once transition (Delivering -> Closed)
   through a typed API on the reservation/lease (e.g. `Reservation::publicationFinished()`), so
   `/stats` delivering accounting and capacity release follow the transport truth, not a timer.
2. **No second authority**: the caller must not mutate the lease directly (test-only transitionTo
   remains banned in production paths); only the executor/lease-owner APIs move state.
3. **Backpressure/HTTP pool**: the pool width = `servingHttpWorkerCount(R, headroom)` (slice 2);
   no server-local second count.

## Slices (after A-3 acceptance)

- S1: `PublicationLease` close path + `Snapshot` accounting assertion (delivering decrements only
  on transport completion; focused regression: slow consumer holds delivering until completion).
- S2: ServerMode wiring: after the response stream finishes, call the typed publication-close;
  HTTP pool uses `servingHttpWorkerCount`.
- S3: boundary/preflight regressions: exactly-once retirement (double-close refused), delivering
  accounting under a slow consumer + cancellation; then lift `serving-capacity-lease-lifetime`
  (deny rule) only after S1-S3 + the PMA BOM slice are accepted.

## Evidence rules (known reviewer standards)

- Deterministic latched interleavings; no sleeps as enqueue evidence (Snapshot.pending / owned CVs).
- Boundary fixtures at the actual Q/S/R limits with negative controls.
- Immutable packets: candidate tree == gate tree (write-tree proof); expanded commands,
  stdout+stderr+exit, binary SHA/ELF, variant header hashes.
