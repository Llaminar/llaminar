# Retained native storage wire composition

**Status:** design for adaptive pooled storage, deferred for the current fully
resident eight-MI50 pipeline target. That target needs fixed source ranges and
only the pipeline stage containing the single main PLE layer consumes lookup
results. The bounded active-child primitive passed CUDA2/ROCm2 native replay;
this does not qualify the adaptive archive described below.

The real retained model should record each addressed storage transfer once on its original pair, then clone each endpoint at the corresponding transfer stage frontier. The shared unit is one wire operation. A complete source parent can use many such operations. Current source, reader, storage and expert parents keep their own graph topology, stream, arena, preparation token and launch identity. This plan depends on successful CUDA and HIP active-child replay in the bounded proof packet.

## Operation and endpoint authority

1. Extend `PooledImmutableDirectedOwnerProgram` with a typed wire projection of its existing ordered owner recipe. Each operation carries the physical edge coordinate, family, role, endpoint, maximum bytes and extent class. Project the complementary source side with the existing extent and source-slice laws. Pin Commands, Free Decisions, Victim Decisions and Read Requests have a source-slice producer and a receive-slice consumer. Ordinary counted operations use a producer prefix and producer-publication consumer. Both sides retain the same exact message key, admitted payload capacity and original edge direction. The owner recipe remains the validator for the full owner DAG and the mapped flat certificate continues to derive from it.
2. Add an internal pair accessor on `PooledImmutableRemoteTransport` that dispatches the typed family and role to the existing Pin, PinReturn, Free, Victim, Source, Publication, Read and Retirement wave bindings. The live accessor yields the two actual stable binding objects. Check both descriptors against the projection, including the direction, endpoint identities, source slice and actual native context coordinates. Build the projection from planned geometry for BOM and from the original prepared owner/coordinator plans for materialization. Seal the same ordered inventory before the first archive recording. A C0 edge has 22 fixed operations. A positive edge adds 11 counted operations. Each operation has two graph definitions, one per actual endpoint. Same-device storage has no remote edge. Cross-vendor edges retain the existing mapped TransferEngine program.
3. `PooledImmutableDirectedTransport::create` already constructs the actual storage union, the original immutable operand/receipt roots, and all final holders. Add a distinct retained-native-storage creation scope from `PooledImmutableRetainedParticipants::create`. After those holders are finalized and before `prepareOriginalOwners`, record and seal the archive. This includes same-vendor inline-reader storage owners. Existing direct native component callers keep their explicit binding type. Archived storage bindings always require the matching sealed definition. They cannot execute a fresh native library enqueue when a definition is missing. Reader Result/ACK, local-hot admission and request-counted compact transfers keep their existing source/reader authority.
4. Prepare each archive endpoint on its actual original worker/stream using the existing original storage/setup acquisitions and `PooledImmutableNativeTransfer::prepare`. Record the existing `PooledImmutableNativeTransfer::enqueue` body into a graph-only definition on each endpoint. Its bytes, operands, receipt, root offsets, source bounds, original context and backend generation come from the final binding. The device still publishes live length, slice, errors and completion. The cold recording scope must dispatch both endpoints before joining either, close both captures before sealing, and abort the original context before draining on any submission/recording failure. Extend `OriginalNativeGraphCaptureGroup` with a typed addressed-edge form based on the actual `NativeByteEdge` and original context. Reuse its ready-future failure handling and standard timeout. Its current overload requires all actual members, so two jobs passed to that overload would be rejected for a larger storage union. A pair records two actual library endpoints. It creates no second communicator or operations for uninvolved members. Use the ordered recipe to batch the cold dispatch per physical edge once pairing and native order are verified. Per-edge work is bounded by the physical wire inventory and independent of model variant count.

## Capture import and model integration

`PooledImmutableTransferBinding` is the common seam for the eight storage transfer stage classes. Bind the archive slot to the final stable endpoint before any stage computes its capture signature. Its full existing native operand identity remains present. Add the sealed slot owner identity and exact endpoint identity. Require the actual original binding/slot object and owner provenance in addition to any signature. The sealed archive is immutable for one original prepared source. A different graph stream may use the same child when the active capture and actual worker/device/context all authenticate the original edge.

At graph construction the storage stage derives `CollectiveGraphCaptureAuthority` from its typed binding. Archive-backed native wire stages qualify as `ParticipantLocalCapturedTransfer` under the existing capture classification because each performs a local import of a sealed definition. Their semantic wire transport remains `NativeCollective`. Direct native library stages and model-reader Result/ACK retain `RuntimeBackend`. This is required by `DeviceGraphExecutor::recordGraphCaptureBody`, which already rejects runtime collectives in participant-local setup captures. Manual replay still rejects these transfer stages. The original stage buffer contracts and `ScopedGraphCaptureStage` dependency ledger continue to own producer and consumer publication.

Expose a narrow active import operation through `ScopedBackendGraphCapture`. Its exact current worker, capture and expected stage stream authorize a sealed child use. The guard already brackets native begin/end and installs the dependency ledger. Give it the active import capability for that interval without exposing a raw graph pointer to transfer callers. The `RetainedParticipantGraphExecutable::RecordingCapture` facade must forward import to its owned native recorder in Recording phase. CUDA/HIP append the child after the actual current frontier, then make it the new frontier using the bounded proof's backend primitive. Validate each actual requested archive slot from its endpoint binding. A model parent may import all of its declared operation frontiers in DAG order. The proof's single-child member belongs to the proof owner and does not become a model parent limit. Prebind the archive borrow and operation roster cold. A stage import allocates no application storage and does not call NCCL/RCCL setup again.

`prepareOriginalOwners` keeps its existing `Standalone`, `EmbeddedParent`, `EmbeddedExpert` and `InlineReader` dispositions. The existing exact owner graph, phase stages, `captureSetupGraphFragment`, owner `General` reservation, graph-only seal or executable instantiation remain. An owner-side transfer stage imports its archived child at the original point. Source and inline-reader graphs created later use the same persistent holders, so the same binding operation applies to their corresponding stage. The existing `SourcePlan::requireDeclaration`, `bindOriginalSource` and `RetainedGraphParticipantPreparationStream` continue to authenticate each exact ComputeGraph, arena, variant, stream and topology generation. `recorded_source_boundary` still publishes the actual source definition during the original TP capture boundary. `attach_original_parent` still seals the actual finite auxiliary source/reader body and attaches it after that variant's own Probe. Full source/reader and storage attachment association stays unchanged. Each newly recorded variant checks its own graph and wire occurrences before its seal. Share the wire records only. Hash, Probe, Compact, result buffer, verifier width, output pointer, force/prefix branch and retirement computation remain part of the variant that owns them.

## Ownership and retirement

Use one source-owned archive containing participant-local banks of sealed graph-only definitions. Each bank retains original prepared permits and the original transport's operand/receipt/context lifetime. Wave bindings select fixed archive slots without a strong back-edge from archive to wave/transport. The transport owns the archive and original roots in a defined retirement order. Materialization remains entirely under the existing original PMA. Resource records and graph-definition counts are metadata for the original ownership scope.

Retain one typed archive use per actual capture/cache owner, covering the ordered operations on its device. Authenticate it before the first SDK mutation and keep it through parent destruction, including a failed partial import. `GraphSegmentCache::reset` already observes its original terminal and destroys `retained_parent_capture` before clearing segments and `original_storage_attachment`. Retain the archive through that boundary. Extend the existing original generation-parent attachment lifetime to cover DGO clones after a recording unit has been cloned. An archive lease must follow the enclosing backend handle or existing cache attachment and cannot belong solely to the temporary `ScopedBackendGraphCapture`. Original owner bodies retain a corresponding archive use until `releaseOriginalRemoteDefinition` destroys their native captures. Existing source preparation, auxiliary-body and enclosing-parent tokens remain independent authorities. No raw pointer or weaker source token substitutes for one of those claims.

In `retireOriginalRuntimeBeforeArenaRelease` keep the existing original terminal waits, parent/cache borrower checks and remote owner definition release. Explicitly retire the archive after all source, reader, embedded expert and standalone owner graph borrowers have drained. Destroy the child definitions on their original workers before `retireOriginalInvocation` and `PooledImmutableDirectedTransport::retireOriginalRuntime` revoke the native transport and its roots. Apply the same order on cold-construction failure. Keep the original failure, abort the original communicator if capture began, drain already submitted work, retire all successfully recorded definitions, then release original graph and transport obligations. A live lease blocks archive retirement before any backing root is revoked. Request reset changes existing device state and keeps this entire topology.

## Physical memory

`PooledImmutableRetainedParticipantBudget::completeBOM` is already called from the ordinary, reuse and distributed memory planners. `slotDependentBOM` is already called by optional placement. Add the wire archive projection there before the current non-inline owner skip. Retain existing `PooledImmutableDirectedTransport::completeBOM` roots and existing independent owner `nativeStorageBOM` lines. Archive pricing covers the actual original devices that have archived storage edges, including the source and any inline storage reader. Only known endpoint graph object/record bytes grow with the projected operation list. The count on a device is the sum of `22 + (positive ? 11 : 0)` over its incident actual native storage edges. Thus one positive edge adds 33 graph-only definitions at each end. It does not add 66 executable allowances. Use a bounded trailing-record root for the bank and charge the existing `nativeGraphCaptureObjectBytes` per actual backend graph object on original CPU0. The graph objects have no SDK executable or launch owner. Keep both the exact count and allocator purpose during materialization, including the C0 floor and positive delta. Planner and materializer consume the same projection.

Use one typed aggregate opaque graph-only allowance for the complete archive population on each participating original device, billed to the existing native-storage purpose and process lifetime. The existing General host and device ceilings are the candidate upper bounds for that aggregate. The current General executable certificate does not establish that those ceilings cover this separate archive. Confirm them on the complete actual fixed/positive archive population and shipped backends before using the contract for admission. Do not price one General unit per wire child, claim the independent executable's existing unit twice, use the mapped flat certificate or derive a live budget from an allocator sample. `GPUGraphMemoryContract` already owns the aggregate observation rule and conservative upper-bound values. Use that contract and a closed graph-only archive shape. `NativeAuxiliaryResourceCatalog` currently has only read-ahead, ordering and mapped owner program classes. No source hashes or new calibration/admission subsystem are needed. The bounded child proof deliberately charges the existing General contract for its five proof definitions and cannot serve as the complete archive population measurement. The production archive needs a graph-only bank owner with one aggregate PMA obligation and per-record object claims. Creating one `RetainedParticipantGraphExecutable` through the current General factory for every archive record would charge the wrong lifetime and resource class. The bank can reuse the original worker/permit checks, exact native object claims, off-worker retirement discipline and protected import primitive from that class.

## Qualification order

1. Run the bounded CUDA and HIP shared-child tests and the original host lifetime negatives. Verify source variant parents and receiver handle all live extents, empty traffic, and early retirement. The bounded fixture records all three parents on their existing endpoint streams. The production archive qualification must also cover a parent recorded on a different exact admitted stream of the same prepared worker, because original source-cache variants may own different streams.
2. Exercise the full production wire recipe on the actual original native storage union, including a wider ROCm cohort, C0, positive capacity, all required wire frontiers, a source-slice and changing live byte counts, and both directions. Check the cold recorded count equals the projection and is independent of source variants. Check native opaque pool growth for the complete archive under existing aggregate evidence and setup wall time. Reject a missing frontier, mismatched role/slice/endpoint, incompatible prepared owner and borrower retirement before transport teardown. Explicitly register focused coverage in ProductionTestPreflight.
3. Exercise the actual retained-model preparation and source-parent capture paths. Require at least two real variant tokens with distinct model shape/purpose and the same sealed wire bank, exact storage/reader ownership, first request, continuation, prefix, force, reset and teardown. Assert actual NativeStorageGraphExecutable PMA lines, actual archive definition count, zero new native wire recording after cold setup and exact live payload/receipt behavior. Then qualify real QFN with the original hardware policy. The bounded proof and existing pooled component tests do not qualify this model path.
